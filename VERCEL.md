# Vercel — Fast Equb only

1. Import repo `Menelik2/game`
2. **Root Directory:** `apps/equb`
3. Framework: Next.js
4. Install: `npm install`
5. Build: `npm run build`
6. Deploy

Do **not** set root to `apps/web` (legacy multi-game casino UI).

The live product is **Equb rooms only** (`/` → home, `/rooms` → play).
